# Open-Source Picks
### Free, open-source projects worth knowing — curated from my last 3 months of research on X
*Godwin Agbane · GBEDEGU '26 · August 2026*

Everything here is free to use and open source. Star what's useful; self-host what saves you money. (A few links were shortened in the original posts — search the project name on GitHub if a link moves.)

## AI agents & assistants

- **DeepSeek Harness** — github.com/deepseek-ai/deepseek-harness — MIT-licensed, plugin-based coding-agent harness; a free alternative to commercial coding agents (121K+ stars).
- **Onyx** — github.com/onyx-dot-app/onyx — open-source AI assistant with RAG and 50+ connectors; self-host your own "company AI".
- **OpenBot** — github.com/CopilotKit/openbot — open-source AI-coworker platform: computer use, human handoffs.
- **goose (Block)** — github.com/block/goose — self-hosted AI agent framework from Jack Dorsey's Block; channels, search, Git integration.
- **OpenClaw** — docs.openclaw.ai — open-source agent platform with a large contributor community.
- **Hermes** — MIT-licensed bot framework; runs locally, lets you assign a different model to every agent.
- **The Agency** — an open-source "AI company": 147 pre-configured agents working together.
- **Graphiti** — github.com/getzep/graphiti — long-term memory for AI agents via context graphs (29K+ stars).
- **agent-scripts (steipete)** — Peter Steinberger's open-sourced Claude Code loadout — great for seeing how a power user structures agents.
- **GitHub Spec Kit** — github.com/github/spec-kit — spec-driven development toolkit for working with AI agents.
- **230+ prebuilt Claude Code agents** — community repo of role-based subagents (engineering, marketing, design, security).

## Content & media

- **OpenCut** — github.com/OpenCut-app/OpenCut — free open-source CapCut alternative video editor (60K+ stars, MCP server in the works).
- **voicebox** — github.com/jamiepine/voicebox — local, open-source ElevenLabs alternative for voice (51K stars).
- **MoneyPrinterTurbo** — github.com/harry0703/MoneyPrinterTurbo — topic → finished short video, automatically.
- **Palmier** — open-source Mac-native AI video editor designed so AI assistants can drive the edit.
- **Mono Charts / Amicro** — amicro.vercel.app — open-source animated React charts + UI library.
- **Morphicons** — 7KB icon-morphing animation library.
- **Data Formulator (Microsoft)** — github.com/microsoft/data-formulator — plain-English data → charts.

## Research, documents & knowledge

- **MinerU** — github.com/opendatalab/MinerU — converts PDFs to clean markdown for AI/RAG pipelines.
- **Prompts Chat** — prompts.chat — huge community prompt library.
- **public-apis** — github.com/public-apis/public-apis — 1,000+ free APIs for anything you're building (462K stars).
- **Hubble** — free open-source Markdown notepad built for humans + agents working together.
- **Clone-Wars** — github.com/GorvGoyl/Clone-Wars — 100+ open-source clones of Netflix/Airbnb/Spotify-class apps — read real codebases free.
- **World Monitor** — open-source live global-intelligence dashboard: 3D globe, 500+ news feeds.

## Infrastructure & security (for the technical)

- **Authentik** — github.com/goauthentik/authentik — self-hosted SSO/MFA identity platform; replaces expensive enterprise auth.
- **n8n** — github.com/n8n-io/n8n — open-source workflow automation with AI-native nodes; self-host for the cost of a small server.
- **Claude-BugHunter** — github.com/elementalsouls/Claude-BugHunter — MIT; turns Claude into a security scanner for your own apps (71 bug-bounty skills).
- **greenlight (RevylAI)** — github.com/RevylAI/greenlight — scans your mobile app for App Store / Play Store compliance issues before submission.
- **OpenHaystack** — github.com/seemoo-lab/openhaystack — build DIY "Find My" trackers from cheap Bluetooth hardware.
- **DigitalPlat FreeDomain** — github.com/DigitalPlat/FreeDomain — free domain registration + DNS setup guide.
- **Graphify** — maps any codebase into a knowledge graph.

## Open models (run AI on your own hardware)

- **GLM (Z.ai)** — open-weights frontier model family; quantized versions run on consumer hardware via Unsloth.
- **Kimi K3 (Moonshot)** — open-source model with 1M-token context.
- **Slime (THUDM)** — github.com/THUDM/slime — the RL training framework behind GLM.
- **SLAM3R** — real-time 3D scene reconstruction from a single ordinary video.
- **text-to-cad** — open-source harness that turns coding agents into CAD engineers (STEP/STL/gcode output, 10K stars).
